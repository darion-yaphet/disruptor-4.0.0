== About This Fork

This repository is a fork of https://github.com/LMAX-Exchange/disruptor[LMAX-Exchange/disruptor], maintained with the assistance of LLM (Large Language Model) tooling.

All credit for the original design and implementation goes to the LMAX Development Team. This project stands as a tribute to their groundbreaking work on mechanical sympathy and lock-free inter-thread messaging.
